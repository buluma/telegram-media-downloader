## Current strengths

- Auth uses hashed passwords, persisted random sessions, timing-safe verification, and authenticated WebSocket upgrades.
- Docker builds run as a non-root user, include a healthcheck, and use pinned Node/Bun versions.
- CI covers Node 22, 24, and 26 across Linux and macOS, with lint, docs, tests, dependency audit, CodeQL, and image smoke tests.
- Database migrations are numbered and transactional.
- Backup enqueue ordering, cloud confirmation, and cache eviction are covered by regression tests.
