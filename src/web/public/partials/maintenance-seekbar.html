Sprite settings

Defaults are tuned for hover scrubbing on Telegram clips; tweak only if your library has very long files or very tight disk budget.

Enable seekbar previews

Master switch. When off, no new sprites are generated and the player falls back to the time-only tooltip on hover.

Auto-generate on download

Every newly-downloaded video gets a sprite in the background. Realtime jumps ahead of any backfill in flight.

How many sprite encodes the Go sidecar runs in parallel. 4 is the sweet spot on 4–8-core hosts.

Hardware acceleration

Auto picks the best backend per platform (cuda → vaapi → qsv on Linux x86, videotoolbox on macOS, cuda → qsv → d3d11va on Windows, v4l2m2m on Pi). Falls back to CPU silently.

Auto is safe; pick a specific backend only after the probe shows it works. The sidecar silently falls back to CPU if the chosen backend can't initialise on this host.
