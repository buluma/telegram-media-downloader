                                Face clustering
                            

                        
                        
Detects faces with insightface, groups recurring people into clusters via DBSCAN.

                        
                        


                        

                            
                            

                                

                                    
Run AI subsystem

                                    
Master switch. When off, no scans run, the sidecar stops accepting work, and auto-index on new downloads is skipped.

                                

                                

                            


                            
                            

                                

                                    
Auto-scan new downloads

                                    
When on, every newly-downloaded photo is queued for face detection in the background. Turn off to scan only via the buttons above.

                                

                                

                            


                            
                            

                                
                                
                                
Switching the model requires a Re-cluster — embedding spaces differ across presets.

                            


                            
                            

                                

                                    
                                    1.05
                                

                                
                                
Calibrated on real 900+ photo data. 0.8–1.0 = strict (precise). 1.05 = peak (recommended). 1.10+ starts merging different people; 1.15+ collapses everyone into one mega-cluster.

                            


                            
                            

                                
                                
                            


                            
                            

                                

                                    

                                        
Include videos in face grouping

                                        

                                            Samples video frames and runs face detection on those frames. Off by default.
                                        

                                    

                                    

                                

                                

                                    

                                        
                                        
                                    

                                    

                                        
                                        
                                    

                                

                                

                            


                            
                            

                                

                                    

                                        
Hardware acceleration

                                        
Detect which GPU/CPU backend this host can run the face model on. CUDA → CoreML → DirectML → OpenVINO → CPU, in order of speed.

                                    

                                    
                                

                                

                                
                                
                                
Auto is the safe default; pick a specific backend only after a probe shows it works. Falls back to CPU if the chosen backend isn't available.

                                Image tagging

Image tagging

                                    
When on, photos are tagged with semantic labels. Requires the AI subsystem to be enabled.

                                

                                

                            


                            
                            

                                
                                
                                
One per line or comma-separated. Leave empty to use the sidecar's built-in 49-tag vocabulary.

                            


                            
                            

                                
                                

                                    
                                    0.35
                                

                                
Lower = more tags per photo (more noise). Higher = only high-confidence matches.
